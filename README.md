# Git e GitHub

Repositório destinado ao estudo e à prática de Git e GitHub, com foco em controle de versão e organização do desenvolvimento de software.

## Objetivo

Praticar Git e GitHub por meio do desenvolvimento de um site simples, utilizando diferentes recursos do versionamento durante sua construção.

## Conteúdos praticados

- Criação e gerenciamento de repositórios
- Commits e histórico de alterações
- Branches
- Desenvolvimento de funcionalidades em branches
- Merge
- Conflitos e resolução de conflitos
- Organização do histórico
- Mensagens de commit
- Fluxo de trabalho com Git e GitHub

## Registro de conflito

O arquivo `conflito.txt` contém a saída do Git durante a simulação do conflito em `src/index.html`.
